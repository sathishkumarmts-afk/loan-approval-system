## 📊 Design System

### Color Palette
```
Primary:    Teal #1B8B7E      (professional, trustworthy)
Accent:     Light Teal #4ECDC1 (highlights, CTAs)
Success:    Green #27AE60     (approve decisions)
Error:      Red #E74C3C       (reject decisions)
Warning:    Amber #F39C12     (review decisions)
Background: #F8FAFB           (clean, minimal)
Surface:    #FFFFFF           (cards, inputs)
Text:       #2C3E50           (primary text)
Secondary:  #7F8C8D           (labels, captions)
Border:     #E8EEF1           (dividers, borders)
```

### Typography
```
H1:  32px  weight 700  teal
H2:  20px  weight 600  teal
H3:  16px  weight 600  dark gray
Body: 14px weight 400  dark gray
Label: 12px weight 600 light gray
Small: 12px weight 400 light gray
```

### Spacing (8px Base)
```
Micro:  8px
Small: 16px
Medium: 24px
Large: 32px
Extra:  48px
```
